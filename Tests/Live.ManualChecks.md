# Live: ручная проверка перед v1.5.0-beta.2

Перезапустите Git-версию. Проверяйте набором с клавиатуры, не вставкой готового
примера: Live отслеживает ввод. Каждый пример начинайте в пустом поле.

`│` означает место запуска Live и не вводится. Для режима hotkey нажмите
Win+F9 (или своё сочетание); для DoubleSpace нажмите два пробела. Эти режимы
выбираются отдельно в настройках. DoubleSpace оставляет один пробел в конце.

## Базовые случаи — повторить обоими триггерами

| Набрать и запустить | Ожидаемый текст после hotkey |
|---|---|
| `Ghbdtn vbh│` | `Привет мир` |
| `руддщ цщкдв│` | `hello world` |
| `[kt,│` | `хлеб` |
| `Hello world/ Ghbdtn vbh│` | `Hello world. Привет мир` |
| `Hello world. Ghbdtn vbh│` | `Hello world. Привет мир` |
| `Привет [kt, vbh│` | `Привет хлеб мир` |
| `Hello руддщ│` | `Hello hello` |

Для смешанного набора переключайте системную раскладку между русским и
английским участком. Смена алфавита между словами ограничивает исправление
последним участком; смысл текста автоматически не угадывается.

## Продолжение без паузы

Включите автоматическое переключение раскладки. Наберите `Ghbdtn`, вызовите
DoubleSpace и сразу продолжайте физическими клавишами V, B, H. Ожидается
`Привет мир`, без ведущей латинской буквы, пропусков или дублирования.

Повторите, продолжая клавишами [, K, T, запятая: ожидается `Привет хлеб`.
Повторите с V, B, Backspace, H: ожидается `Привет мр`.

Обратный тест: в RU наберите `руддщ`, DoubleSpace, сразу клавиши W, O, R, L, D.
Ожидается `hello world`. Повторите через hotkey, предварительно оставив один
пробел после исходного слова: hotkey сам пробел не добавляет.

Выключите автопереключение и повторите: раскладка должна остаться прежней,
продолжение должно соответствовать нажатым клавишам в ней.

## Абзацы и положение курсора

1. Наберите `Привет мир`, Enter, Enter, `Ghbdtn vbh`, затем Live.
   Первые два абзаца сохраняются; последняя строка становится `Привет мир`.
2. Наберите `Ghbdtn`, переведите курсор стрелкой или мышью в другое место,
   вызовите Live без нового набора. Старый фрагмент не должен удаляться.
3. Во время Live быстро наберите продолжение и переключитесь в другое поле
   либо окно. Скрытый текст старого поля не должен вставляться в новое.
   Если он ещё был в очереди, появится пункт «Копировать отложенный ввод»
   в меню значка Layout Toolkit. Проверьте восстановленный текст.
4. При быстром продолжении нажмите Enter/Tab. Проверьте отсутствие потери
   скрытого текста: он должен быть доступен через пункт восстановления,
   если команда смены места ввода прервала его выпуск.

## Clipboard и приложения

Скопируйте заранее `CLIPBOARD_SENTINEL`. Выполните несколько Live-конвертаций,
затем вручную вставьте clipboard в отдельное поле. Должен остаться именно
`CLIPBOARD_SENTINEL`; он не должен сам появляться вместо исправления.

Повторите базовые и быстрые случаи в Блокноте, браузерном textarea и обычном
поле мессенджера. Отдельно повторите через Sunshine/Moonlight и под нагрузкой.
Приложение может не принимать Unicode keyboard input или запрос HKL — это
нужно проверить в реальном окружении; автоматический тест не заменяет эту часть.

При сбое запишите приложение, триггер, состояние автосмены раскладки, точный
набор, позицию запуска и результат. Особенно полезно указать, исчезал ли
текст, переставлялся ли или просто оставался в прежней раскладке.
