# Общее переключение раскладки: ручная проверка перед v1.5.0

Перезапустите Git-копию после обновления исходников. В «Обзоре» включите
«Переключать раскладку после исправления» и сохраните настройку.
Для Full/Majority выделяйте всю строку; для Live набирайте текст вручную.

| Режим | Исходный текст | Ожидаемый текст | Раскладка после |
|---|---|---|---|
| Full, Win+F12 | `Ghbdtn vbh` | `Привет мир` | RU |
| Full, Win+F12 | `Привет мир` | `Ghbdtn vbh` | EN |
| Majority, Win+F11 | `Привет мир Ghbdtn` | `Привет мир Привет` | RU |
| Majority, Win+F11 | `Hello world руддщ` | `Hello world hello` | EN |
| Full, Win+F12 | `Ghbdtn Привет` | `Привет Ghbdtn` | Не меняется |
| Full, Win+F12 | `Ghbdtn USB` | `Привет USB` | RU (USB — исключение) |
| Majority, Win+F11 | `abc абв` | `abc абв` | Не меняется |
| Любой режим | `12345` | `12345` | Не меняется |

Повторите первые четыре случая с выключенной настройкой: текст исправляется,
раскладка не меняется. Для Live проверьте `Ghbdtn` → `Привет`/RU и
`руддщ` → `hello`/EN обоими триггерами; DoubleSpace оставляет один пробел.

Во время получения/подготовки выделенного текста смените окно или поле ввода:
другое поле не должно получить исправленный текст или запрос смены раскладки.
Проверьте сохранение общего переключателя после перезапуска и отсутствие
его дубля в Live-разделе, включая нативный интерфейс.

Приложение может проигнорировать запрос Windows на смену языка ввода.
Это не должно приводить к сообщению об ошибке уже выполненной конвертации.
