# Changelog

## [v1.5.0-beta.2] - 2026-09-23

### Добавлено

- Опциональное переключение раскладки целевого приложения после успешной
  Live-конвертации: EN → RU выбирает установленную русскую раскладку, RU → EN —
  установленную английскую. Настройка по умолчанию выключена и действует для
  запуска как по горячей клавише, так и по двойному пробелу.
- Запрос смены раскладки отправляется сфокусированному элементу исходного окна
  через `WM_INPUTLANGCHANGEREQUEST`, без эмуляции системных сочетаний клавиш.
- Установщик распознаёт старые установки по ярлыку `Layout Toolkit RU-EN.lnk`,
  переносит их на `install.json` и заменяет старый ярлык автозагрузки новым.
- Для новой интерактивной установки используется системный выбор папки вместо
  ввода пути в PowerShell; подпапку `Layout Toolkit` можно создать одним ответом.
- Компактная приветственная справка в светлой и тёмной теме WebView2. При
  недоступности веб-интерфейса открывается короткое нативное окно.

### Исправлено

- Исправлена опечатка `Toolkir` в имени папки Windows-архива,
  допущенная в v1.4.1 и повторённая в v1.5.0-beta.1. Начиная с
  v1.5.0-beta.2 используется имя `Layout Toolkit Ru En`.
- При обновлении установщик переносит установку из папки с `Toolkir`
  в исправленную папку `Toolkit`, обновляет `install.json` и ярлык.
- Live передаёт исправленный текст через Unicode-ввод без изменения clipboard
  и без Ctrl+V; удалено фиксированное ожидание восстановления clipboard.
- Переносы строк и табуляция завершают текущий фрагмент. При смене алфавита
  между словами исправляется последний участок, без захвата предыдущего языка.
- Отложенный ввод больше не обрезается до 300 символов. При смене места ввода
  он сохраняется для копирования через меню значка программы.
- Клавиши отложенного ввода переводятся через установленную целевую раскладку,
  включая пунктуационные клавиши; Backspace обрабатывается в очереди.
- Успех смены раскладки проверяется по фактическому HKL. Отказ приложения не
  считается ошибкой уже выполненной текстовой замены.
- Быстрый ввод во время Live-конвертации временно буферизуется
  и выпускается только после замены текста и запроса новой раскладки.
  Это предотвращает перемешивание первых символов продолжения с
  исправленным фрагментом.
- Запрос смены раскладки выполняется после отправки Unicode-ввода. Если focused
  HWND не применил HKL, выполняется повторная попытка через исходное top-level
  окно с повторной проверкой фокуса.
- Настройки показывают небольшое окно загрузки, пока WebView2 не отрисует
  интерфейс; пустое окно больше не появляется. При закрытии WebView2 выгружается,
  а повторное открытие создаёт его заново.
- Live-раздел помещается без прокрутки в стандартном окне 800×540: выбор
  способа запуска и интервал расположены рядом с соответствующими хоткеями.

### Совместимость

- Смена раскладки выполняется в best-effort режиме: отдельные приложения могут
  проигнорировать запрос Windows, но это не отменяет успешную замену текста.

## [v1.5.0-beta.1] - 2026-09-20

Предварительная версия масштабного редизайна Windows-интерфейса.

### Добавлено

- Локальное веб-окно настроек на Microsoft Edge WebView2: навигация,
  Live, Unicode, захват горячих клавиш и работа со списком исключений.
- Компактное окно Unicode Input в том же стиле: HEX-предпросмотр,
  история и автоизбранное в двух колонках, быстрый выбор и параметры сочетаний.
- Общая светлая и тёмная тема для веб-настроек и Unicode Input. Переключатель
  возвращён в заголовок окна, а выбор сохраняется между запусками.
- Тема применяется также к нативным заголовкам окон через DWM и обновляется без
  пересоздания HWND; для ранних сборок Windows 10 предусмотрен атрибут `19`.
- На Windows 10 заголовок принудительно перерисовывается при смене темы, поэтому
  после возврата к светлой теме не остаётся чёрной полосы окна. Для обхода кеша
  DWM выполняется незаметное изменение размера без пересоздания HWND.
- Unicode Input прогревается скрыто после запуска и переиспользует один WebView2:
  после вставки окно скрывается, а не создаётся заново при каждом вызове.
- Окно Unicode Input показывается только после явного ответа HTML/JavaScript;
  тайм-аут загрузки открывает нативный интерфейс вместо пустого серого окна.
- Исправлена видимость прогретого Unicode Input: при показе включается
  `IsVisible` самого WebView2, а не только его родительского AHK-окна.
- Явное сохранение настроек, проверка значений, предупреждение о несохранённых
  изменениях при переходе между разделами и откат INI при ошибке применения.
- Изолированные тесты настроек и связи HTML/JavaScript с AutoHotkey.
- Добавлен `install.ps1` для установки и обновления Windows-версии одной
  командой с проверкой размера и SHA-256 релизного архива.

### Совместимость

- Уплотнён веб-интерфейс: стандартное окно 800×540, минимальное — 720×480;
  навигация и сохранение закреплены, содержимое адаптируется к размеру окна.
- Восстановлен исходный порядок действий в списке горячих клавиш.

- При недоступности WebView2 открывается прежнее окно настроек.
- Движок конвертации и остальные окна пока остаются на AutoHotkey.
- Парсер, история, статистика избранного и вставка Unicode остались в AHK;
  при ошибке WebView2 открывается прежнее окно Unicode Input.
- В Windows-сборку необходимо включать `Assets/WebSettings`,
  `Assets/WebUnicodeInput` и `Modules/Vendor`.

## [v1.3.3] - 2026-08-16

### Исправлено

- Live-режим теперь переносит завершающий знак предыдущего предложения в
  заменяемый фрагмент: искажённые раскладкой `/`, `&`, `ю` и `,`

- Полное исправление больше не сохраняет пунктуацию и не применяет специальные
  правила для скобок или пары `/ ↔ .`: однозначные RU- и EN-токены целиком
  преобразуются по таблице физических клавиш.

## [v1.3.2] - 2026-08-12

### Исправлено

- `Win + F12` теперь определяет направление конвертации отдельно для каждого
  непробельного токена. Это позволяет одновременно исправлять смешанный текст

- Конечные `.`, `,` и `?` сохраняются как пунктуация. Скобочные символы

  а внутренние `/` и `.` образуют симметричную пару `/ ↔ .` независимо от
  направления токена.

## [v1.3.1] - 2026-08-11

### Исправлено

- Исправлен запуск Layout Toolkit при нестандартной или portable-установке AutoHotkey v2:
  - путь к AutoHotkey определяется через сохранённый выбор пользователя, данные установки Windows, файловую ассоциацию, `PATH` и стандартные каталоги;
  - если автоматический поиск не помог, можно вручную указать любой существующий `AutoHotkey.exe` версии 2;

  - скачать актуальный стабильный установщик с официального сайта и установить AHK для текущего пользователя;
  - указать уже существующий AutoHotkey v2;
  - отменить запуск.

- `Run_Layout_Toolkit.cmd` и `Startup_Manager.cmd` переведены на общий помощник `Resolve_AutoHotkey.ps1`, поэтому поиск AHK больше не дублируется в двух файлах.

- Ярлык автозагрузки теперь при каждом запуске использует общий поиск AutoHotkey, а не навсегда запоминает один предполагаемый стандартный путь.

- Исправлен путь к иконке ярлыка автозагрузки: используется `Assets\icon.ico`.

## [v1.3] - 2026-08-11

### Что нового

#### Windows

- Полностью упрощено **исправление раскладки по `Win + F12`**:
  - каждая русская буква переводится в английскую с той же клавиши, а каждая английская — в русскую;
  - цифры, пробелы и пунктуация не анализируются и остаются без изменений;
  - слова из словаря исключений по-прежнему сохраняются без изменений.

- Добавлен альтернативный запуск **Live-конвертации по горячей клавише**:
  - в настройках можно выбрать запуск двойным пробелом или горячей клавишей;
  - по умолчанию по-прежнему выбран двойной пробел;
  - стандартная горячая клавиша Live-конвертации — `Win + F9`;
  - двойной пробел после исправления оставляет один пробел, а горячая клавиша ничего не добавляет в конец;
  - интервал между пробелами скрывается, когда выбран запуск по горячей клавише;
  - повторное нажатие горячей клавиши во время уже выполняющегося исправления игнорируется.

- В разделе **Горячие клавиши** добавлен захват сочетаний прямо из окна настроек:
  - сочетания можно назначать без ручного редактирования файла;
  - одинаковое сочетание нельзя сохранить сразу для двух функций;
  - одиночные буквы, пробел и другие клавиши обычного набора защищены от случайного назначения без `Ctrl`, `Alt`, `Shift` или `Win`;
  - дополнительные пользовательские записи в `hotkeys.ini` при сохранении остаются без изменений;
  - ручное редактирование, применение файла и сброс к стандартным сочетаниям сохранены.

- Полностью переработан **Unicode Input**:
  - вместо простого диалога добавлено отдельное окно поверх остальных окон;
  - добавлен мгновенный предпросмотр вводимого символа или последовательности;
  - сохранены режимы вставки в активное окно и копирования в буфер обмена;
  - после вставки фокус возвращается в исходное окно;
  - `Enter` применяет результат, `Escape` закрывает окно.

- Добавлена **история Unicode-символов**:
  - сохраняются до 5 уникальных HEX-кодов с визуальным предпросмотром;
  - при использовании последовательности каждый входящий в неё код добавляется в историю;
  - пункт можно применить мышью или выбрать сочетанием `Ctrl + 1…5` по умолчанию;
  - история сохраняется между запусками в `Documents\Layout Toolkit\settings.ini`.

- Добавлено автоматически формируемое **избранное**:
  - Layout Toolkit запоминает часто используемые последовательности из двух и более Unicode-кодов;
  - по умолчанию последовательность попадает в избранное после двух использований;
  - избранное сортируется по частоте использования и показывает до 5 паттернов;
  - одиночные символы в автоизбранное не добавляются;
  - пункт можно применить мышью или выбрать сочетанием `Shift + 1…5` по умолчанию.

- Добавлены настройки Unicode Input:
  - **Подтверждать выбор при помощи Enter** — сочетание сначала фокусирует пункт, после чего выбор подтверждается клавишей `Enter`; при отключении пункт применяется сразу;
  - **Перемещать историю при сохранении** — повторно использованный код поднимается наверх; при отключении существующий порядок сохраняется, а наверх добавляются только новые коды;
  - для быстрого выбора истории и избранного можно отдельно назначить `Ctrl`, `Shift`, `Alt`, `Win` или `Tab`;
  - если выбрать уже занятую клавишу, назначения истории и избранного меняются местами;
  - когда выбран `Tab`, обычный переход между полями клавишей Tab в окне Unicode Input отключается;
  - настройки продублированы в общем окне Layout Toolkit и синхронизируются с окном Unicode Input;
  - изменения из окна Unicode Input автоматически сохраняются в `settings.ini` сразу после выбора.

- Улучшен ввод HEX-кодов:
  - короткие одиночные коды можно вводить без ведущих нулей: `AB`, `60`, `1F600`;
  - сохранена поддержка последовательностей через пробел или перенос строки и слитных блоков по 4 HEX-символа;
  - HEX-буквы `A–F` распознаются даже при включённой русской раскладке: физические клавиши `ф/и/с/в/у/а` работают как `A/B/C/D/E/F`;
  - для пробела, табуляции и переводов строки добавлены понятные обозначения в предпросмотре.

### Исправлено

- Полностью переработана защита **Live-режима** от ложного двойного пробела:
  - любая другая физическая клавиша между пробелами сразу отменяет ожидание live-команды;
  - `Shift + Space` остаётся обычным пробелом;
  - `Ctrl + Space`, `Alt + Space` и `Win + Space` не воспринимаются как live-команда;
  - второй пробел больше не пропадает, если направление раскладки не определено или конвертация невозможна;
  - пробелы, введённые во время уже выполняющейся замены, остаются обычным вводом и не запускают отложенную конвертацию.

- Исправлена работа Live-режима при очень быстром наборе:
  - символы, введённые сразу после двойного пробела, больше не теряются и не удаляются вместе с исходным фрагментом;
  - ввод, накопленный во время замены, сохраняется и возвращается после исправленного текста;
  - `Backspace` корректно учитывается во время выполняющейся live-операции;
  - переход по тексту, клик мышью или смена активного окна безопасно отменяют устаревшую замену.

- Исправлена долговременная работа Live-режима.
  Перехват ввода больше не останавливается после достижения стандартного лимита `InputHook` в 1023 символа.

- Live-режим теперь распознаёт обычные `.`, `?`, `!` и `…` как завершение предложения, а не только их варианты, искажённые неверной раскладкой.

### Технические изменения

- `Assets\hotkeys.default.ini` стал единственным источником стандартных горячих клавиш:
  - удалены дубли заводских сочетаний из основного скрипта;
  - пользовательский `hotkeys.ini` накладывается поверх стандартного файла;
  - при отсутствии стандартного файла текущий пользовательский файл больше не перезаписывается встроенным набором.

- Live-перехват переведён на `InputHook("V L0 I1")`:
  - снято ограничение длины перехватываемого ввода;
  - искусственный ввод AutoHotkey отделён от физических нажатий пользователя;
  - добавлено отслеживание всех непечатных клавиш через `NotifyNonText`.

- Удалена старая блокировка ввода через `g_Suppress` и связанная с ней задержка после отправки пробела.

- Переработана логика `g_LiveBusy` и pending-буфера:
  - добавлена привязка live-операции к активному окну и явная инвалидизация контекста;
  - замена исходного фрагмента и восстановление быстрого последующего ввода выполняются одной последовательностью;
  - завершение операции и перенос pending-буфера защищены от пересекающихся обработчиков.

- В секцию `[UnicodeInput]` файла `settings.ini` добавлены данные и параметры:
  - `History`;
  - `ConfirmSelectionWithEnter`;
  - `MoveHistoryOnUse`;
  - `HistoryShortcutModifier`;
  - `FavoriteShortcutModifier`;
  - `PatternStats`;
  - `AutoFavoritesMinUses`;
  - `AutoFavoritesMax`.

- Статистика Unicode-паттернов ограничена 30 записями, чтобы `settings.ini` не разрастался бесконечно.

  - `Assets\hotkeys.default.ini` используется как заводской шаблон;
  - если пользовательский файл отсутствует, он создаётся автоматически;
  - если заводской файл недоступен, используется встроенный fallback стандартных хоткеев.

- Добавлена возможность подключать дополнительные пользовательские хоткеи через секцию `[Hotkeys]`.
  Это создаёт базовую основу для будущих пользовательских модулей и plug-in системы.

- Добавлен рабочий раздел **Исключения**:
  - отображение пользовательского `Documents\Layout Toolkit\exclude.txt`;
  - отображение заводского `Assets\exclude.default.txt`;
  - отображение количества загруженных записей;
  - кнопка **Открыть exclude.txt**;
  - кнопка **Перезагрузить** без перезапуска Layout Toolkit;
  - кнопка **Сбросить стандартные** с восстановлением заводского словаря.

- Добавлены GUI-настройки **Live-режима**:
  - включение и выключение live-режима из окна настроек;
  - настройка `DoubleSpaceMs`;
  - настройка показа расширенной подсказки при первом включении;
  - сохранение параметров в `Documents\Layout Toolkit\settings.ini`.

- Обновлено окно первого обучения:
  - теперь оно описывает не только базовые хоткеи, но всю систему Layout Toolkit;
  - добавлено описание Layout Fix, Live-режима, Unicode Input, CapsLock Fix, пользовательских файлов и Settings GUI;
  - хоткеи в тексте подтягиваются из текущих значений `hotkeys.ini`;
  - окно стало компактнее и использует прокручиваемую область текста.

- Добавлен **Unicode Input**:
  - ввод Unicode-символов по HEX-коду;
  - поддержка одиночного кода: `2014` → `—`;
  - поддержка нескольких кодов через пробел: `0060 2014 0060` → `` `—` ``;
  - поддержка слитного ввода блоками по 4 символа: `006020140060` → `` `—` ``;
  - хоткей открывает режим вставки символа в активное окно;
  - кнопка из Settings GUI открывает то же окно в режиме копирования результата в буфер обмена.

- Добавлен **CapsLock Fix**:
  - исправление регистра выделенного текста;
  - примеры:
    - `пРИВЕТ` → `Привет`;
    - `эТО ПРИМЕР` → `Это пример`;
    - `тАК. пРИМЕР` → `Так. Пример`;
    - `GitHUB` → `GitHub`;
    - `POWERSHELL` → `PowerShell`;
  - используется `exclude.txt` для восстановления канонического написания технических слов.

- Пользовательские настройки и словарь исключений перенесены в:
  - `Documents\Layout Toolkit\settings.ini`;
  - `Documents\Layout Toolkit\hotkeys.ini`;
  - `Documents\Layout Toolkit\exclude.txt`.

- Добавлена мягкая миграция старых пользовательских данных:
  - старый `settings.ini` из `%APPDATA%\LayoutToolkit`;
  - старый `exclude.txt` рядом со скриптом.

- В трей-меню добавлены и обновлены пункты:
  - **Настройки...**;
  - **Открыть папку Layout Toolkit**;
  - **Открыть exclude.txt**;
  - **Перезагрузить словарь исключений**.

- Двойной клик по иконке Layout Toolkit в трее теперь открывает окно настроек.

- Пункт live-режима в трее отображается как чекбокс.

### Исправлено

- Убраны захардкоженные хоткеи из текстов разделов настроек.
  Теперь GUI берёт отображаемые сочетания из текущих значений `hotkeys.ini`.

- Исправлено ложное срабатывание live-режима при очень быстром наборе текста.
  Теперь второй пробел считается двойным пробелом только если между двумя пробелами не было обычного ввода.

- Исправлено выключение live-режима:
  - при выключении реально останавливается `InputHook`;
  - пробел снова нормально доходит до игр и приложений.

- Улучшена логика словаря исключений:
  - `exclude.txt` хранит не только факт исключения, но и каноническое написание;
  - это позволяет восстанавливать правильный регистр: `pOWERSHELL` → `PowerShell`.

- Улучшена работа Settings GUI:
  - live-контролы показываются только в разделе **Live-режим**;
  - остальные разделы сохраняют нормальный размер текстовой области;
  - разделы настроек обновляют отображение после действий reload/reset.

- Улучшено окно обучения:
  - текст больше не растягивает окно за пределы экрана;
  - основной текст помещён в прокручиваемое поле;
  - убрано случайное выделение текста при открытии;
  - исправлено лишнее жирное начертание текста.
